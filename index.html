Hello there! This layout is a bit more complicated than my previous layouts, so I will write some important info and instructions here.
Read me
  • This layout includes :
    /fonts
    - index.html (using external files for CSS and JS)
    - index_with_everything.html (CSS, HTML and JS on the same page)
    - style.css
    - script.js
    - quick instructions.txt
    - user manual.txt
  • All windows are draggable. You can minimize them to the taskbar or close them. The maximize button is included for style only and is disabled in this layout.
  • You can change the icons to your own liking. The icons used here are from Pixel art icons. I have converted SVGs to PNGs here.

    You can find classic Windows icons here.

    This site also has a great collection of old web icons.

    Note: You may need to crop some icons if they appear too small.
  • The icons on the left side can behave as normal links opening another page.
  • Or they can open windows like this one. Test by clicking "about me" "credits" or "paint".

    Popup window content is edited in the hidden HTML sections near the bottom of the page.

    Windows can be any size you want.

    Windows open in random positions by default. You can also make the window open at a specific location (instructions are in the user manual).
  • The links in the Start menu are normal links.
  • To add music to the CD player, you need a direct audio file link, usually ending in .mp3.
  • You can edit this layout as much as you want if you are comfortable editing HTML/CSS.
  • Please read the user manual carefully.
